# StudySensi — Minimal Recommender Chatbot (MVP)


This repo contains a small demo of a learning recommendation chatbot (StudySensi). It uses a toy MostPopular recommender, a FastAPI backend, and a Streamlit frontend.


## Quickstart (local)


1. Clone the repo
2. Create virtualenv and install requirements:


```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
